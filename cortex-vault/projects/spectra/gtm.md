# GTM & Growth Strategy

## Strategy: Product-Led Growth (PLG)
Dev discovers → tries free → shares report → team adopts → enterprise expands

## 3 Growth Loops
1. **Viral Report Loop** — beautiful reports get shared → teammates see branding → they run Spectra
2. **Badge Loop** — README badges ("Score: 85/100 A-") → visitors click → run Spectra → add their own
3. **Benchmark Loop** — anonymous aggregate scores by language/framework → devs compare → run Spectra
