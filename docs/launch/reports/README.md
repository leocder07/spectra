# Sample Spectra Reports

These are real Spectra reports, generated by running `spectra analyze` on
public OSS repositories. They ship with the codebase as living examples
of what the tool produces — and they let new users browse a real report
before installing.

> **Why these "View rendered" links?** GitHub renders `.html` files as raw
> source code when you click them in the file browser. The links below
> wrap the raw URL through [htmlpreview.github.io](https://htmlpreview.github.io/)
> so the report displays as a real web page in your browser.

## How to regenerate

```bash
pip install spectra-ai
export ANTHROPIC_API_KEY=sk-ant-...
spectra analyze https://github.com/expressjs/express \
  --output docs/launch/reports/express.html \
  --max-cost-usd 25
```

For the Spectra self-scan (because the regex fixtures in the test suite
trip the secret pre-flight by design), pass `--allow-secrets`:

```bash
spectra analyze . \
  --output docs/launch/reports/v0.6.0/spectra-self.html \
  --allow-secrets \
  --audit-sink "file:docs/launch/reports/v0.6.0/audit.jsonl" \
  --max-cost-usd 25
```
