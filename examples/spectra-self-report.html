Performance (1)

medium Retry decorator lacks exponential backoff jitter and has fixed overhead ~2.0h ▶
src/spectra/infrastructure/retry_decorator.py
The retry_decorator.py implements retry logic for LLM API calls but appears to use a simple fixed or linear backoff strategy. Without jitter, multiple concurrent retries (especially in a future parallel execution model) will create thundering herd problems against the LLM API, leading to cascading rate limit failures and increased total wait time.
Recommendation: Implement exponential backoff with full jitter: `delay = random.uniform(0, min(max_delay, base_delay * 2 ** attempt))`. Also consider adding a circuit breaker pattern to fail fast when the API is consistently unavailable, rather than burning through all retry attempts.
estimated effort: ~2h
